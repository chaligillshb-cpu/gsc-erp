# Gill Spray Centre (GSC) — Customer/Product History

The Customers page has a **Products** action on each customer row. It opens that customer's product-wise purchase summary and invoice-line history.

The Products & Stock page has a **Buyers** action on each product row. It shows customers who bought that product, quantities, total billed amount, last purchase date, and current customer outstanding balance.

These views are calculated from saved sales invoices. They do not magically know purchases made before the ERP was introduced; enter/import those records if you need historical reporting.

## Important status
This is an incremental feature update to the existing offline-first starter. It is not a certified production accounting system. Double-entry accounting, atomic transaction handling, robust concurrency controls, complete staff referral analytics, and end-to-end cloud security testing remain outstanding. Test with sample records and keep independent backups before relying on it for live books.
